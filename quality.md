# Quality

## Definition of Done (any artifact)
- Answers the eight README questions or equivalent clarity.
- Uncertainty is visible where it exists.
- Public/private boundary respected.
- Cross-links to Grove and relevant services present.
- STATUS.md and mermicorn.repo.yaml updated.
- No secrets, no invented authority claims.

## Quality Gates by Type

### Research / Comparison
- Multiple sources checked where feasible.
- Total cost or full evidence set shown.
- Ranked recommendation with clear trade-offs.
- Source timestamps / volatility notes.

### Design / Creative
- Concept statement + silhouette + palette + materials.
- Multi-angle or multi-state visuals.
- Production hand-off package complete.
- Difficulty and open questions listed.

### Commerce Package
- Structured record with confidence levels.
- Comps from completed sales preferred.
- Listing + campaign assets + next actions.
- Objection / follow-up sequences where relevant.

### Gaming Content
- Actionable, role-appropriate advice.
- Clear fan-project / responsible-play disclaimers.
- No guaranteed-outcome language.

## Non-negotiables
- No empty repositories or placeholder theater.
- No silent assertion of authenticity, grade, booking power, or brokerage.
- Simple for Cherry.
