## Critical Design Rule

Do not dump a full heavy system onto Cherry. Give a simpler boot, smaller memory model, strong visual interfaces, guided workflows, clear next actions, domain examples, automation behind the scenes, and progressive technical exposure.

Feel: *“I know what to do next, and the machine helps me do it well.”*
