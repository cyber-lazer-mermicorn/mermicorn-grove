# Contributing

This constellation is owned and operated by Cherry (Cyber Lazer Mermicorn).

## How to contribute
1. Open an issue describing the change or gap.
2. Work on a feature branch.
3. Keep commits atomic and descriptive.
4. Update `STATUS.md` and `mermicorn.repo.yaml` when the change affects state or contract.
5. Prefer the shared Command Board for task tracking once available.

## Standards
- Follow the eight README questions.
- Keep public/private boundaries strict.
- No secrets in any repository.
